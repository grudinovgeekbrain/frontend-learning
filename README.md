# Кварта — лендинг кофейной мастерской

Учебное тестовое задание для VitAi World. Next.js App Router + TypeScript + SQLite.

## Что реализовано
- Адаптивный лендинг: ассортимент, подписка, история мастерской, доставка, контакты и форма.
- Серверная проверка белорусского номера телефона.
- Защита от повторной заявки с тем же номером в течение 10 минут.
- Сохранение заявок в SQLite, UTM-меток, страницы входа и referrer.
- Сообщения об успехе и ошибках, блокировка кнопки на время отправки.
- Open Graph metadata и поддержка reduced motion.

## Локальный запуск
Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. SQLite-файл создаётся в `data/leads.sqlite`.

## Проверка API

```bash
curl -i -X POST http://localhost:3000/api/lead \
  -H 'Content-Type: application/json' \
  -d '{"name":"Тест","phone":"+375 29 123-45-67","interest":"question","comment":"Проверка"}'
```

Повторите запрос с тем же номером в течение 10 минут: ожидаемый ответ — HTTP 409.

## Развёртывание
SQLite требует постоянного диска. Для Render Web Service можно использовать `render.yaml` с persistent disk и `DATA_DIR=/var/data`. Не размещайте эту SQLite-базу на эфемерной файловой системе serverless-платформы: данные могут пропасть после перезапуска. Для Vercel лучше заменить SQLite на управляемую базу данных и адаптировать API.

## Допущения и ограничения
- Менеджер связывается с клиентом вручную; корзины и оплаты нет.
- Номер сохраняется в международном формате `+375...`.
- Telegram-уведомления не добавлены, поскольку они необязательны.
- Перед сдачей проверьте права и условия использования выбранных фотографий.
- Реальные секреты, CRM-интеграция, мониторинг и отдельная политика хранения персональных данных не настроены.
